# Orvyn

Your knowledge. Organized.

Orvyn is a self-hosted knowledge management
and real-time collaboration platform.

## Features

- Collaborative document editing
- Knowledge management
- Workspaces and databases
- OpenID Connect authentication
- S3-compatible attachment storage

## Deployment

This chart includes optional PostgreSQL,
Valkey and SeaweedFS services.

External infrastructure can be configured
using the installation options.
