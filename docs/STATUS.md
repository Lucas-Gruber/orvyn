# Implementation status
This is an actively developed application, not completion of Phase 1 or the master specification.

Implemented and integration-tested: local credentials, email verification, SMTP password reset, session administration, audited authentication, OIDC with admin UI and signed protocol tests, login cookie, logout invalidation, private spaces, safely confirmed team conversion, verified email invitations, team roles and inherited page restrictions, page hierarchy/search/moves/trash/restore/history, Tiptap block editing, automatic CRDT persistence, live carets/presence, two-replica synchronization, reconnect and active rights revocation, private S3 attachments with image previews and orphan/retention cleanup, isolated database/object-bucket restore validation, structured databases with full record-pages, typed properties including membership-validated Person fields and record-scoped Files fields, five saved views, server-side filters/sorts/pagination, live Kanban and private-record notifications, linked database blocks with independent saved views, CSV mapping/preview/atomic import and scoped CSV/JSON export, page creation/listing/update, PostgreSQL document storage, origin checks, owner isolation, stale-write rejection. The UI supports real account and page operations; it contains no seeded product content.

Incomplete: additional authentication hardening (identity linking, OIDC group mappings and real-provider validation), organizations and ownership transfer, remaining block types, drag-and-drop, collaboration comments/mentions and production load testing, production object-store policies and scheduled backups, remaining database property types (Relation/Formula/Rollup), templates, Markdown/hierarchy import and portable JSON restore, whiteboards, sharing, branding, localized UI, bundled fonts and full theme system, Nuxt UI shared components, Tauri desktop, Kubernetes/Helm, observability, production disaster-recovery validation, release/versioning/signing, accessibility audit and broader browser E2E coverage.

Next: complete remaining property types and database templates, then whiteboards and explicit public sharing. Migration tooling and account lifecycle tests are implemented. Preserve all master requirements in PRODUCT.md.
