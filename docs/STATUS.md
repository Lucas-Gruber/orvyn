# Implementation status

This is an actively developed application, not completion of Phase 1 or the master specification.

See the [complete open-items audit](OPEN_ITEMS.md) for the current missing features, partial implementations, unresolved installation/CI issues, outstanding production validation and explicitly deferred extensions. It cross-checks the specification and subsequent requests against the implementation; older feature documents may still contain stale TODOs.

Server release **0.3.1** completed successfully, including multi-architecture images and the public OCI chart. Version **0.3.2** adds sidebar resizing and rendering actions for existing Mermaid code blocks; matching artifacts become available after its tag-triggered release completes. The separate main CI has an unresolved intermittent database modal test failure; the 0.3.1 release CI passed the complete suite. Rancher catalog visibility remains a separate installation issue. MCP and Tauri desktop applications are not implemented.

Slash commands and selected-text links can target whole documents or stable heading anchors across authorized spaces, with read-only copying, local sign-in continuation and missing-heading handling. Document and heading preview cards resolve currently authorized titles/excerpts without copying target content into the source document. Permission-filtered backlinks are indexed transactionally, backfilled for existing documents and available with pagination in the document UI. Page discussion threads support Commenter roles, replies, versioned author editing, moderation, resolve/reopen, scoped pagination and in-memory drafts. Text-selected comments use validated Yjs relative positions, local highlights and thread markers, with explicit changed/deleted quotation states. Discussion composers and rich documents support permission-filtered @ selection; inline document nodes store only IDs and resolve current identities. An in-app inbox persists comment/document mentions, reply notifications and read state while resolving current titles/excerpts and permissions. Page/space activity records committed actions without copied content, coalesces document edits and filters private record/admin events by current access. It supports real account and page operations and contains no seeded product content. See UI.md for device-preference and accessibility boundaries.

Table and board edits additionally retain local cell drafts through failed writes, refresh and filtering, with per-record queues, conflict review, explicit retry/discard and navigation/unload protection. Drafts remain in memory and are cleared when access is revoked; forced reload/crash recovery is not implemented.

Property management supports naming, stable option IDs/order/colors, soft deletion/restoration with retained values, schema conflict checks and saved-view repair. Saved views also support independent property ordering, visibility controls, table-header drag/keyboard reordering and persistent column widths. Widths support pointer previews, keyboard limits/reset, cancellation, live readers, template ID remapping and conflict-safe view writes without changing record values or discarding failed cell drafts. Space owners can review scalar field type changes across up to 5,000 records, retain originals and restore unchanged values while preserving newer edits. Signed snapshots, explicit clearing, idempotence and atomic view/search/history repair protect the conversion. Additional types and batch conversion remain unfinished. Existing references and ACL checks remain authoritative after restoration.

Two-way relations create a matching property with editor rights to both schemas, maintain both sides atomically during edits/imports/templates, preserve unseen links and enforce 50 stored links per record/property. Self-links and concurrent opposite writes are covered. Deleting either property disconnects the pair while retaining values; existing populated one-way fields cannot yet be converted in place.

Editor columns now retain shared proportions with pointer/keyboard resizing, cancellation and independent undo. Block controls support nested selection and movement between columns, callouts, quotes, toggle bodies and the document, including native drag, searchable destinations, outdent and preservation of empty source containers. Lists and tables still move as intact blocks.

Rollups can compose across two relation steps, respecting independent database/record access at each step. Queries and exports use consistent schema/value snapshots, and leaf changes refresh visible source rows across replicas. Dense results use permission-checked five-second refreshes with compatible legacy-client signals. Longer paths, externally dependent target formulas and production graph/load testing remain outstanding.

Workspace search also indexes stored scalar database values, current option labels/tags and configured CreatedTime/LastEditedTime metadata. It offers title/document/property scopes and shows only matching property lines in safe highlighted previews. Record/option/schema edits, restoration, imports and templates update the projection transactionally; current page access remains authoritative. Reference/computed fields and identity metadata remain excluded rather than cached into another result.

Text links use pointer cursors in editable and read-only documents. See EDITOR_TABLES.md for validation and remaining boundaries.

Kanban cards now open records without inline property editing, show nonempty fields and private first-image previews, and support visible scoped drag/drop plus keyboard/menu movement. Pending moves use the existing retained-draft/conflict queue. See KANBAN.md for image priority, permissions, cancellation and ordering boundaries.

Whiteboard pages and direct document embeds now use the native Excalidraw interface, with private owned images, durable element collaboration, current permission checks, text search, portable import/export and recovery checkpoints. Browser tests cover drawing, undo/redo, export, embedding, independent image imports, navigation flushing, restoration and live revocation. See WHITEBOARDS.md for bounds and remaining work.

Public document/folder/whiteboard snapshot links now have explicit scope review, optional passwords and expiry, disabling/revocation and an isolated responsive reader. Source policy changes permanently revoke affected links. Preview freshness, exact file grants, anonymous API isolation and current access checks are covered. See PUBLICATIONS.md for behavior and limits. Database sharing also selects a saved view, individual rows and visible properties, excludes original record bodies by default and renders all five views with scoped item dialogs. Explicit body inclusion, selected file/relation values, view filters, 205-row pagination and independent record publish permissions are covered. Hierarchical navigation adds local search, breadcrumbs and a mobile page picker. Publication requests recover through automatic/manual retry with the same reviewed request ID. Direct record-page publishing also selects properties independently, preserves private parent/sibling data and supports approved record links without publishing a database view. Public formulas recompute only explicitly selected inputs, exclude private cached values and hidden relations, and retain numeric/boolean display and finite/null rules. Public rollups support seven aggregates, two explicit relation steps, selected target fields and dependent formulas without copying private totals. Public people fields and mentions use explicitly authored aliases with root-scoped opaque IDs; the private picker resolves only selected current readers and never autofills account addresses. Identity formulas and rollup targets operate only on approved aliases.

Single-page Markdown files/pasted text can now be reviewed and imported as native editable blocks. Native blocks have readable Markdown conversions with notes; file links keep their original authentication requirements, and record parents/properties remain separate. Round trips cover stable heading links, nested tasks, code endings and GFM code pipes. Complete archives and hierarchy imports remain outstanding. See MARKDOWN_EXPORT.md.
