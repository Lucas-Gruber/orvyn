# Implementation status

This is an actively developed application, not completion of Phase 1 or the master specification.

Implemented and integration-tested: local credentials, email verification, SMTP password reset, session administration, audited authentication, OIDC with admin UI and signed protocol tests, login cookie, logout invalidation, private spaces, safely confirmed team conversion, verified email invitations, team roles and inherited page restrictions, page hierarchy/search/moves/trash/restore/history, Tiptap block editing with H1–H4 headings across Markdown/slash/toolbar/shortcuts and permanent anchors, including callouts, local collapsible sections, dynamic tables of contents and language-selectable syntax-highlighted code, private image/file blocks with upload and permission-checked previews/downloads, opt-in sandboxed video embeds for YouTube/Vimeo/Loom, responsive two/three-column layouts, floating text selection formatting and whole-block selection/reordering with native drag handles, automatic CRDT persistence, live carets/presence, two-replica synchronization, reconnect and active rights revocation, private S3 attachments with image previews and orphan/retention cleanup, isolated database/object-bucket restore validation, structured databases with full record-pages, typed properties including membership-validated Person fields, record-scoped Files fields, same-space Relation fields with readable target selection, live titles/access changes and filtered query/export/import semantics, typed Formula properties with stable references and server-side calculated filters/sorts/exports, direct-relation Rollup counts/numeric aggregates over current readable targets, database/record snapshot templates with independently copied attachments and rebound schema/document references, editable side/center/full-page record views, five saved views, server-side filters/sorts/pagination, live Kanban and private-record notifications, linked database blocks with independent saved views, CSV mapping/preview/atomic import and scoped CSV/JSON export, page creation/listing/update, PostgreSQL document storage, origin checks, owner isolation, stale-write rejection. The UI includes a redesigned workspace shell, folders and a collapsible hierarchy with native drag placement and keyboard reorder/nest/outdent, indexed permission-filtered title/document search with excerpts and space/type filters, favorites/recent pages, page/space emoji icons and preset covers, private attachment-based page covers, persistent page URLs, automatic title saves, shared dialogs and menus, responsive navigation, seven themes and locally bundled fonts. Slash commands and selected-text links can target whole documents or stable heading anchors across authorized spaces, with read-only copying, local sign-in continuation and missing-heading handling. Document and heading preview cards resolve currently authorized titles/excerpts without copying target content into the source document. Permission-filtered backlinks are indexed transactionally, backfilled for existing documents and available with pagination in the document UI. Page discussion threads support Commenter roles, replies, versioned author editing, moderation, resolve/reopen, scoped pagination and in-memory drafts. Text-selected comments use validated Yjs relative positions, local highlights and thread markers, with explicit changed/deleted quotation states. Discussion composers and rich documents support permission-filtered @ selection; inline document nodes store only IDs and resolve current identities. An in-app inbox persists comment/document mentions, reply notifications and read state while resolving current titles/excerpts and permissions. Page/space activity records committed actions without copied content, coalesces document edits and filters private record/admin events by current access. It supports real account and page operations and contains no seeded product content. See UI.md for device-preference and accessibility boundaries.

Table and board edits additionally retain local cell drafts through failed writes, refresh and filtering, with per-record queues, conflict review, explicit retry/discard and navigation/unload protection. Drafts remain in memory and are cleared when access is revoked; forced reload/crash recovery is not implemented.

Property management supports naming, stable option IDs/order/colors, soft deletion/restoration with retained values, schema conflict checks and saved-view repair. Saved views also support independent property ordering, visibility controls and table-header drag/keyboard reordering, with matching exports, template ID remapping and safe retention of failed cell drafts. Property type conversion and column resizing remain unfinished. Existing references and ACL checks remain authoritative after restoration.

Editor columns now retain shared proportions with pointer/keyboard resizing, cancellation and independent undo. Block controls support nested selection and movement between columns, callouts, quotes, toggle bodies and the document, including native drag, searchable destinations, outdent and preservation of empty source containers. Lists and tables still move as intact blocks.

Incomplete: additional authentication hardening (identity linking, OIDC group mappings and real-provider validation), organizations and ownership transfer, remaining block types, individual list-item/table-row restructuring, production load testing, production object-store policies and scheduled backups, advanced reciprocal/cross-space relations and multi-hop rollups, search over database property values/tags/metadata, Markdown/hierarchy import and portable JSON restore, whiteboards, sharing, branding, localized UI, synchronized preferences, Tauri desktop, Kubernetes/Helm, observability, production disaster-recovery validation, release/versioning/signing, accessibility audit and broader browser E2E coverage.

Next: follow the ordered checklist in ROADMAP.md, including remaining relation/rollup capabilities and broader search over database fields/tags/metadata. Migration tooling and account lifecycle tests are implemented. Preserve all master requirements in PRODUCT.md.
