# Implementation status

This is an actively developed application, not completion of Phase 1 or the master specification.

Implemented and integration-tested: local credentials, email verification, SMTP password reset, session administration, audited authentication, OIDC with admin UI and signed protocol tests, login cookie, logout invalidation, private spaces, safely confirmed team conversion, verified email invitations, team roles and inherited page restrictions, page hierarchy/search/moves/trash/restore/history, Tiptap block editing with H1–H4 headings across Markdown/slash/toolbar/shortcuts and permanent anchors, including callouts, local collapsible sections, dynamic tables of contents and language-selectable syntax-highlighted code, private image/file blocks with upload and permission-checked previews/downloads, opt-in sandboxed video embeds for YouTube/Vimeo/Loom, responsive two/three-column layouts, floating text selection formatting and whole-block selection/reordering with native drag handles, automatic CRDT persistence, live carets/presence, two-replica synchronization, reconnect and active rights revocation, private S3 attachments with image previews and orphan/retention cleanup, isolated database/object-bucket restore validation, structured databases with full record-pages, typed properties including membership-validated Person fields, record-scoped Files fields, Relation fields across independently authorized spaces with searchable target selection, live titles/access changes and filtered query/export/import semantics, typed Formula properties with stable references and server-side calculated filters/sorts/exports, direct-relation Rollup counts/numeric aggregates over current readable targets, database/record snapshot templates with independently copied attachments and rebound schema/document references, editable side/center/full-page record views, five saved views, server-side filters/sorts/pagination, live Kanban and private-record notifications, linked database blocks with independent saved views, CSV mapping/preview/atomic import and scoped CSV/JSON export, page creation/listing/update, PostgreSQL document storage, origin checks, owner isolation, stale-write rejection. The UI includes a redesigned workspace shell, folders and a collapsible hierarchy with native drag placement and keyboard reorder/nest/outdent, indexed permission-filtered title/document search with excerpts and space/type filters, favorites/recent pages, page/space emoji icons and preset covers, private attachment-based page covers, persistent page URLs, automatic title saves, shared dialogs and menus, responsive navigation, seven themes and locally bundled fonts. Slash commands and selected-text links can target whole documents or stable heading anchors across authorized spaces, with read-only copying, local sign-in continuation and missing-heading handling. Document and heading preview cards resolve currently authorized titles/excerpts without copying target content into the source document. Permission-filtered backlinks are indexed transactionally, backfilled for existing documents and available with pagination in the document UI. Page discussion threads support Commenter roles, replies, versioned author editing, moderation, resolve/reopen, scoped pagination and in-memory drafts. Text-selected comments use validated Yjs relative positions, local highlights and thread markers, with explicit changed/deleted quotation states. Discussion composers and rich documents support permission-filtered @ selection; inline document nodes store only IDs and resolve current identities. An in-app inbox persists comment/document mentions, reply notifications and read state while resolving current titles/excerpts and permissions. Page/space activity records committed actions without copied content, coalesces document edits and filters private record/admin events by current access. It supports real account and page operations and contains no seeded product content. See UI.md for device-preference and accessibility boundaries.

Table and board edits additionally retain local cell drafts through failed writes, refresh and filtering, with per-record queues, conflict review, explicit retry/discard and navigation/unload protection. Drafts remain in memory and are cleared when access is revoked; forced reload/crash recovery is not implemented.

Property management supports naming, stable option IDs/order/colors, soft deletion/restoration with retained values, schema conflict checks and saved-view repair. Saved views also support independent property ordering, visibility controls, table-header drag/keyboard reordering and persistent column widths. Widths support pointer previews, keyboard limits/reset, cancellation, live readers, template ID remapping and conflict-safe view writes without changing record values or discarding failed cell drafts. Space owners can review scalar field type changes across up to 5,000 records, retain originals and restore unchanged values while preserving newer edits. Signed snapshots, explicit clearing, idempotence and atomic view/search/history repair protect the conversion. Additional types, batch conversion and history pagination remain unfinished. Existing references and ACL checks remain authoritative after restoration.

Two-way relations create a matching property with editor rights to both schemas, maintain both sides atomically during edits/imports/templates, preserve unseen links and enforce 50 stored links per record/property. Self-links and concurrent opposite writes are covered. Deleting either property disconnects the pair while retaining values; existing populated one-way fields cannot yet be converted in place.

Editor columns now retain shared proportions with pointer/keyboard resizing, cancellation and independent undo. Block controls support nested selection and movement between columns, callouts, quotes, toggle bodies and the document, including native drag, searchable destinations, outdent and preservation of empty source containers. Lists and tables still move as intact blocks.

Rollups can compose across two relation steps, respecting independent database/record access at each step. Queries and exports use consistent schema/value snapshots, and leaf changes refresh visible source rows across replicas. Dense results use permission-checked five-second refreshes with compatible legacy-client signals. Longer paths, externally dependent target formulas and production graph/load testing remain outstanding.

Workspace search also indexes stored scalar database values, current option labels/tags and configured CreatedTime/LastEditedTime metadata. It offers title/document/property scopes and shows only matching property lines in safe highlighted previews. Record/option/schema edits, restoration, imports and templates update the projection transactionally; current page access remains authoritative. Reference/computed fields and identity metadata remain excluded rather than cached into another result.

Incomplete: additional authentication hardening (identity linking, OIDC group mappings and real-provider validation), organizations and ownership transfer, remaining block types, individual list-item/table-row restructuring, production load testing, production object-store policies and scheduled backups, longer rollup chains, search over computed/reference fields and identity metadata, hierarchy imports, attachment bundles and portable JSON restore, further whiteboard conflict/load/compaction work, public branding, localized UI, synchronized preferences, Tauri desktop, Kubernetes/Helm, observability, production disaster-recovery validation, release/versioning/signing, accessibility audit and broader browser E2E coverage.

Document tables now have unobtrusive empty cells, contextual table/row/column controls, header toggles, merge/split, persistent column resizing, a numeric width dialog and keyboard continuation. Native drag cancellation covers Escape, window blur and loss of edit permission. Schema 12 retains unspecified widths in merged cells. Text links use pointer cursors in editable and read-only documents. See EDITOR_TABLES.md for validation and remaining boundaries.

Kanban cards now open records without inline property editing, show nonempty fields and private first-image previews, and support visible scoped drag/drop plus keyboard/menu movement. Pending moves use the existing retained-draft/conflict queue. See KANBAN.md for image priority, permissions, cancellation and ordering boundaries.

Whiteboard pages and direct document embeds now use the native Excalidraw interface, with private owned images, durable element collaboration, current permission checks, text search, portable import/export and recovery checkpoints. Browser tests cover drawing, undo/redo, export, embedding, independent image imports, navigation flushing, restoration and live revocation. See WHITEBOARDS.md for bounds and remaining work.

Public document/folder/whiteboard snapshot links now have explicit scope review, optional passwords and expiry, disabling/revocation and an isolated responsive reader. Source policy changes permanently revoke affected links. Preview freshness, exact file grants, anonymous API isolation and current access checks are covered. See PUBLICATIONS.md for behavior and limits. Database sharing also selects a saved view, individual rows and visible properties, excludes original record bodies by default and renders all five views with scoped item dialogs. Explicit body inclusion, selected file/relation values, view filters, 205-row pagination and independent record publish permissions are covered. Hierarchical navigation adds local search, breadcrumbs and a mobile page picker. Publication requests recover through automatic/manual retry with the same reviewed request ID. Direct record-page publishing also selects properties independently, preserves private parent/sibling data and supports approved record links without publishing a database view. Public formulas recompute only explicitly selected inputs, exclude private cached values and hidden relations, and retain numeric/boolean display and finite/null rules. Public rollups support seven aggregates, two explicit relation steps, selected target fields and dependent formulas without copying private totals. Public people fields and mentions use explicitly authored aliases with root-scoped opaque IDs; the private picker resolves only selected current readers and never autofills account addresses. Identity formulas and rollup targets operate only on approved aliases.

Single-page Markdown files/pasted text can now be reviewed and imported as native editable blocks. Stable headings, checklists, GFM tables, code and inline marks survive conversion; local heading links become permanent page links. Signed content/destination review, current write checks, one-transaction creation and request receipts protect retries, policy changes and failed writes. Source/structure bounds and visible conversion warnings cover HTML, remote images and unsupported links. See MARKDOWN_IMPORT.md.

Markdown export now previews the generated file, copies/downloads exact reviewed content with a shortcut, checks current source/reference access again on download and requires explicit opt-in for visible people names. Native blocks have readable Markdown conversions with notes; file links keep their original authentication requirements, and record parents/properties remain separate. Round trips cover stable heading links, nested tasks, code endings and GFM code pipes. Complete archives and hierarchy imports remain outstanding. See MARKDOWN_EXPORT.md.

Markdown import now accepts bounded UTF-8 file transfers up to 96 KB, including CRLF content whose JSON encoding would exceed the HTTP parser budget. Shared byte limits, pre-upload authorization, exact Unicode metadata, one-file/one-settings validation and no-write rejection remain compatible with reviewed/idempotent imports and existing small JSON clients. Browser coverage includes oversized-file feedback and large-file import/reload.
