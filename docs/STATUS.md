# Implementation status
This is an actively developed application, not completion of Phase 1 or the master specification.

Implemented and integration-tested: local credentials, email verification, SMTP password reset, session administration, audited authentication, OIDC with admin UI and signed protocol tests, login cookie, logout invalidation, private spaces, safely confirmed team conversion, verified email invitations, team roles and inherited page restrictions, page hierarchy/search/moves/trash/restore/history, Tiptap block editing including callouts, local collapsible sections, dynamic tables of contents and language-selectable syntax-highlighted code, private image/file blocks with upload and permission-checked previews/downloads, opt-in sandboxed video embeds for YouTube/Vimeo/Loom, responsive two/three-column layouts, floating text selection formatting and whole-block selection/reordering with native drag handles, automatic CRDT persistence, live carets/presence, two-replica synchronization, reconnect and active rights revocation, private S3 attachments with image previews and orphan/retention cleanup, isolated database/object-bucket restore validation, structured databases with full record-pages, typed properties including membership-validated Person fields and record-scoped Files fields, five saved views, server-side filters/sorts/pagination, live Kanban and private-record notifications, linked database blocks with independent saved views, CSV mapping/preview/atomic import and scoped CSV/JSON export, page creation/listing/update, PostgreSQL document storage, origin checks, owner isolation, stale-write rejection. The UI includes a redesigned workspace shell, folders and a collapsible hierarchy with native drag placement and keyboard reorder/nest/outdent, global permission-filtered title search, favorites/recent pages, page/space emoji icons and preset covers, private attachment-based page covers, persistent page URLs, automatic title saves, shared dialogs and menus, responsive navigation, seven themes and locally bundled fonts. Slash commands and selected-text links can target whole documents or stable heading anchors across authorized spaces, with read-only copying, local sign-in continuation and missing-heading handling. Document and heading preview cards resolve currently authorized titles/excerpts without copying target content into the source document. Permission-filtered backlinks are indexed transactionally, backfilled for existing documents and available with pagination in the document UI. Page discussion threads support Commenter roles, replies, versioned author editing, moderation, resolve/reopen, scoped pagination and in-memory drafts. Text-selected comments use validated Yjs relative positions, local highlights and thread markers, with explicit changed/deleted quotation states. It supports real account and page operations and contains no seeded product content. See UI.md for device-preference and accessibility boundaries.

Incomplete: additional authentication hardening (identity linking, OIDC group mappings and real-provider validation), organizations and ownership transfer, remaining block types, nested block restructuring, mentions, notifications/activity and production load testing, production object-store policies and scheduled backups, remaining database property types (Relation/Formula/Rollup), templates, Markdown/hierarchy import and portable JSON restore, whiteboards, sharing, branding, localized UI, synchronized preferences, Tauri desktop, Kubernetes/Helm, observability, production disaster-recovery validation, release/versioning/signing, accessibility audit and broader browser E2E coverage.

Next: follow the ordered checklist in ROADMAP.md, starting with mentions, notifications/activity, then remaining database types/templates. Migration tooling and account lifecycle tests are implemented. Preserve all master requirements in PRODUCT.md.
