# Document block controls

Hover a block to reveal its left-hand grip. Click for a keyboard-accessible menu with move up/down, move outside container, Move to…, duplicate and delete. Move to… offers searchable destinations in the same document, including columns, callouts, quotes, toggle bodies and the end of the page. Shift-click handles to select a contiguous range; drag any selected grip to move the whole range. A line marks the destination. Grips are also reachable by Tab and are absent in read-only documents. Menu actions include icons and separators between movement and destructive actions.

`Ctrl/Cmd Shift Space` selects the current block or expands a text selection to complete sibling blocks in the nearest editable container. `Alt Shift Up/Down` moves the selection across an adjacent sibling. `Alt Shift Left` moves the selected blocks after the nearest enclosing block. Delete/Backspace removes selected blocks, Escape returns to text editing, and Enter creates a paragraph after the selection. Copy/cut uses a closed ProseMirror slice containing whole blocks. Removing every child of a document, column, callout, quote or toggle body leaves an editable empty paragraph.

These controls work for top-level document children and for blocks inside columns, callouts, quotes and toggle bodies. Blocks can move between those containers using native drag or the destination menu; a selection spanning multiple containers expands to complete common ancestor blocks. Lists and tables move intact and retain their ordinary internal editing commands. Individual list-item/table-row restructuring and marquee selection remain unimplemented. Column resizing is described in EDITOR_LAYOUT.md.

Movement preserves block attributes, marks, file/database/page references, heading IDs and column proportions. Empty source containers retain their wrappers and an editable paragraph. Duplication runs the editor's existing heading identity normalization, leaving the original target intact and generating new IDs for copies. Selected ranges and active drag ranges map through document transactions; invalidated ranges fall back or cancel. The drag payload is scoped to the originating editor. Drops inside the source subtree or into structural wrappers are no-ops. Server validation and edit permissions continue to govern document writes.

Movement, duplication and deletion are distinct history operations. The block extension explicitly uses the same `@tiptap/y-tiptap` undo key as the installed collaboration extension; the separate `y-prosemirror` package remains responsible for shared-schema conversion. No document schema migration is needed: grips, selection, menus and drop indicators are local decorations, never stored in the document.

Model tests verify closed slices, nested selection serialization/bookmarks, mapped edits/deletion, cross-container movement, empty-source preservation, safe destination enumeration, outdent, valid document structure and boundary behavior. Chromium tests use real handles and native drag events, cover cross-column and group movement, destination search/keyboard selection, nested heading duplication, deletion, individual undo, readers without controls and persisted reload. Column-resizing regressions run alongside these tests to keep grips and divider hit areas separate.
